## 📖 Sobre o projeto

A **técnica Pomodoro** divide o trabalho em blocos de foco (tradicionalmente 25 minutos) separados por pausas curtas, com uma pausa mais longa a cada alguns ciclos.

O **Chronos** nasceu como projeto de estudo de React + TypeScript e evoluiu para um app completo: você informa a tarefa, inicia o ciclo e acompanha o progresso. Cada sessão fica registrada em um histórico para você acompanhar seu rendimento.

## ✨ Funcionalidades

- ⏲️ **Timer Pomodoro** com contagem regressiva e tempo exibido no título da aba do navegador
- 📝 **Nome da tarefa** associado a cada ciclo
- 🔁 **Ciclos automáticos** de Foco, Descanso Curto e Descanso Longo, com indicador visual dos ciclos
- 📜 **Histórico** em tabela ordenável (tarefa, duração, data, status e tipo), com status como *Interrompida* e *Abandonada*
- 🗑️ **Limpar histórico** com confirmação antes de apagar
- ⚙️ **Configurações** para personalizar a duração de Foco, Descanso Curto e Descanso Longo
- 🌗 **Tema claro e escuro**
- 🔔 **Notificações** (toasts) para feedback das ações, como "Tarefa Iniciada"
- 🔗 **Navegação entre páginas** com React Router

## 🚀 Como rodar localmente

### Pré-requisitos

- [Node.js](https://nodejs.org/) (versão LTS recente)
- npm (já vem com o Node.js)
- [Git](https://git-scm.com/)

### Passo a passo

```bash
# 1. Clone o repositório
git clone https://github.com/Hennriiqq/chronos-pomodoro.git

# 2. Entre na pasta do projeto
cd chronos-pomodoro

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev
```

Depois, abra o endereço exibido no terminal (geralmente `http://localhost:5173`).
